## Dependency và môi trường

- Thêm đúng 1 devDependency `@vitest/coverage-v8@5.0.1`, 11 package transitive mới; đã so sánh lockfile và **không đổi phiên bản bất kỳ package cũ nào**. Khi nâng Vitest cần nâng provider tương ứng.
- Cài bằng `npm install --ignore-scripts`; không chạy postinstall mới. JaCoCo là Maven test plugin trong profile, không đưa agent vào ứng dụng Docker.
- Node local **24.13.0**, npm **11.6.2**. `jsdom@30.1.0` và hai dependency CSS đã có trước yêu cầu Node `^22.22.2 || ^24.15.0 || >=26.0.0`; npm báo engine warning. Test/build thực tế vẫn đạt, nhưng cần dùng Node tương thích trước nghiệm thu môi trường cuối.
- `npm audit --audit-level=high` **exit 1**: `source-map-js@1.2.1` có 1 advisory high, 0 critical. Gói đã tồn tại trong lockfile trước đợt đo; dùng qua Vite/PostCSS, jsdom/css-tree và nay thêm coverage/magicast. Không phải báo cáo audit sạch.
- [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) mô tả DoS khi xử lý indexed source map có offset không hợp lệ; bản vá **1.2.2**. Các chuỗi dependency build/test có thể dùng parser, nên cần patch và test lại trước phát hành. Không giả định an toàn chỉ vì gói không được import trực tiếp từ source HRM; chưa đánh giá đầy đủ exploitability của từng đường chạy.
- Chưa tự nâng dependency ngoài bộ đo; không chạy `npm audit fix --force`. Việc patch, chạy audit sạch và xác nhận Node được ghi thành task riêng, cần rà soát/test thay đổi lockfile.

## Nguồn kỹ thuật

Thiết lập agent/report theo [JaCoCo Maven](https://www.jacoco.org/jacoco/trunk/doc/maven.html), bản stable theo [JaCoCo changes](https://www.jacoco.org/jacoco/trunk/doc/changes.html). V8 provider/include toàn source theo [Vitest Coverage](https://vitest.dev/guide/coverage.html) và [Coverage config](https://vitest.dev/config/coverage). Vitest có thể ẩn các file 100% khỏi bảng text khi phát hiện AI agent; kiểm tra đủ file bằng JSON, không dựa riêng vào bảng text rút gọn.
