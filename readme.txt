HRM TRUNG TAM NGOAI NGU BINH AN
===============================

De tai: Xay dung he thong thong tin quan ly nhan su cho Trung tam Ngoai ngu Binh An.

Cong nghe: Java 17, Spring Boot 3.5.16, Spring Security, JPA/Hibernate, Maven, React, TypeScript, Vite, MySQL 8, Docker Compose.

Tai khoan demo:
- admin / password: Quan tri he thong.
- hr.manager / password: Quan ly nhan su.
- leader01 / password: Truong nhom.
- employee01 / password: Nhan vien.

Chuc nang demo:
- Dang nhap JWT va phan quyen ADMIN, HR_MANAGER, TEAM_LEADER, EMPLOYEE.
- Quan ly nhan vien, phong ban, chuc vu, hop dong, doi nhom.
- Gui va phe duyet don nghi phep, nghi om, thai san, nghi viec.
- Quan ly ca lam, lich lam, cham cong va tang ca.
- Tinh luong, xem va in bang luong thang/nam.
- Bao cao, tim kiem, loc, sap xep, audit log va backup/restore CSDL.
